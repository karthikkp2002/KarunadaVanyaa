# 🌿 Karunada-Vanya

An interactive Android application built using **Kotlin + WebView** that promotes wildlife awareness, forest conservation, and nature education across Karnataka through a modern mobile experience.

---

# 📱 Project Overview

Karunada-Vanya converts a complete web-based wildlife platform into a native Android application using WebView integration. The app provides educational content, wildlife reporting features, Firebase authentication, and responsive mobile interaction.

The project is designed to support:
- Wildlife awareness
- Forest education
- Real-time reporting
- User interaction
- Educational learning modules

---

## 🔹 Android Features
